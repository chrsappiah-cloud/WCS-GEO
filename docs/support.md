# WCS Mining AI Support

For support with WCS Mining AI, contact World Class Scholars through the GitHub repository support channel:

https://github.com/chrsappiah-cloud/WCS-GEO/issues

When requesting support, include:

- Device model and iOS/iPadOS version.
- App version and build number.
- A short description of the issue.
- Screenshots or steps to reproduce, if applicable.

Please do not include confidential exploration data, passwords, private API keys, or other sensitive information in public support requests.
